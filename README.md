# 待办事项提醒系统 v2

一个零依赖、本地运行的待办事项管理 + 多通道提醒工具。

- 📋 网页管理待办：标题、备注、截止时间、优先级、**多级提前提醒**、重复周期
- 📱 **微信提醒**（PushPlus 免费推送）+ 📧 **邮箱提醒**（SMTP），双通道互为备份
- ⏰ **多级提醒**：一条待办可设置多个提醒点，如提前 1 天 + 1 小时 + 10 分钟
- 🔁 每天 / 每周 / 每月重复提醒，自动排期
- 📊 完成统计看板（今日完成、近 7 天趋势）
- 💾 一键导出备份（JSON / CSV）
- 🔔 浏览器桌面通知（程序开着时秒级弹窗）
- 🖥️ 开机自启选项，关机重启也不错过提醒
- 📝 日志落盘（logs/todo.log，可查提醒历史）
- 💾 数据保存在本地 SQLite（`todo.db`）

## 环境要求

- Windows + Python 3.9+（推荐 3.12），需加入 PATH
- **零第三方依赖**（纯 Python 标准库实现）

## 快速开始

1. 双击 **`start.bat`**（或命令行执行 `python app.py`）
2. 浏览器打开 **http://127.0.0.1:5000**
3. 右上角「⚙️ 设置」→ 配置微信和/或邮箱（见下）→ 保存 → 发送测试
4. 推荐开启「开机自启」，这样电脑一开机提醒服务就在后台运行

## 配置微信通知（PushPlus，免费）

1. 打开 https://www.pushplus.plus ，**微信扫码登录**并关注公众号
2. 页面显示你的 **token**，复制
3. 系统设置页 → 微信通知 → 粘贴 token → 勾选"启用微信提醒" → 保存 → 发送测试

## 配置邮箱提醒（SMTP）

以 **QQ 邮箱**为例：

1. 电脑或手机浏览器登录 QQ 邮箱网页版 → **设置 → 账户**
2. 找到 **POP3/IMAP/SMTP 服务** → 开启 **SMTP 服务**
3. 按提示用手机发送短信验证，获得 **授权码**（16 位字母，**不是登录密码**）
4. 系统设置页 → 邮箱提醒：
   - SMTP 服务器：`smtp.qq.com`　端口：`465`　SSL：开
   - 发件邮箱：你的 QQ 邮箱
   - 授权码：刚生成的那串
   - 收件邮箱：要接收提醒的邮箱
5. 勾选"启用邮箱提醒" → 保存 → 发送测试

> 163 邮箱：`smtp.163.com:465`（同样用授权码）；Gmail：`smtp.gmail.com:587` STARTTLS（应用专用密码）。
> 微信、邮箱可同时启用，任意一个发送成功即视为提醒成功，失败会自动重试。

## 使用说明

- **添加待办**：标题必填；「提前提醒」填分钟数，多个用逗号分隔（如 `1440,60,10` = 提前1天+1小时+10分钟），留空则到点提醒
- **完成**：点击待办左侧圆圈（会记录完成时间并计入统计）
- **编辑 / 删除**：待办右侧 ✏️ / 🗑️
- **筛选**：全部 / 待办 / 已完成
- **统计看板**：页面顶部实时显示今日完成、待办中、累计完成、近 7 天趋势
- **导出备份**：右上角「💾 导出」下载 JSON/CSV
- **桌面通知**：点「🔔 桌面通知」授权后，程序开着时到点会弹系统通知

## 常见问题

- **测试收不到**：确认 token/授权码正确、通道已启用、网络可达
- **邮件提示授权失败**：QQ/163 必须用"授权码"而非登录密码；检查 SMTP 服务器和端口
- **想改端口**：修改 `app.py` 里的 `PORT = 5000`
- **数据备份**：复制 `todo.db`，或用右上角导出功能
- **提醒必须程序在运行**：请开启"开机自启"，或保持 start.bat 窗口开着
