# 待办事项提醒系统

一个零依赖、本地运行的待办事项管理 + 微信提醒工具。

- 📋 网页管理待办：自定义标题、备注、截止时间、优先级、提前提醒、重复周期
- 📱 到点通过 **PushPlus** 免费推送到你的个人微信
- 🔁 支持每天 / 每周 / 每月重复提醒
- 💾 数据保存在本地 SQLite（`todo.db`），不依赖任何第三方服务

## 环境要求

- Windows + Python 3.9 以上（推荐 3.12），需加入 PATH，命令行能执行 `python`
- 无需安装任何第三方 Python 包（纯标准库实现）

## 快速开始

1. 双击运行 **`start.bat`**（或在命令行执行 `python app.py`）
2. 浏览器打开 **http://127.0.0.1:5000**
3. 点击右上角「⚙️ 设置」，配置 PushPlus token（见下）
4. 点「📱 发送测试」，微信收到消息即配置成功

## 配置微信通知（PushPlus，免费）

1. 打开 https://www.pushplus.plus ，用**微信扫码登录**
2. 关注弹出的「推送加」公众号（扫码即可）
3. 登录后页面会显示你的 **token**（一长串字符），复制它
4. 粘贴到本系统的「设置 → PushPlus Token」，点「保存」再点「发送测试」

> 以后到点的待办，会通过公众号推送到你手机微信。未配置 token 时，系统正常工作但不发提醒。

## 使用说明

- **添加待办**：填好标题（必填）、截止时间（可选）、优先级、提前提醒分钟数、重复周期，点「添加」
- **完成**：点击待办左侧圆圈，标记完成 / 恢复待办
- **编辑 / 删除**：待办右侧 ✏️ / 🗑️ 按钮
- **筛选**：全部 / 待办 / 已完成
- **提醒规则**：到「截止时间 − 提前提醒」时推送微信；重复任务推送后自动排到下一次

## 项目结构

```
待办事项提醒项目/
├── app.py            # 主程序（Web 服务 + 定时提醒 + 推送）
├── start.bat         # 一键启动
├── templates/        # 网页模板
├── static/           # 样式与前端脚本
└── todo.db           # 数据文件（自动生成）
```

## 常见问题

- **测试消息收不到**：确认 token 正确、公众号已关注、网络可达 pushplus.plus
- **想改端口**：修改 `app.py` 里的 `PORT = 5000`
- **数据备份**：直接复制 `todo.db` 文件即可
